# ex05 — Structs e `impl`

**Objetivo:** agrupar datos relacionados en un struct y asociarle métodos.

## Conceptos

- Un struct le da nombre a un grupo de campos, y cada campo tiene un tipo.
- `#[derive(Debug, Clone, PartialEq)]` le pide al compilador que genere
  implementaciones útiles por ti.
- `impl` agrega métodos a un tipo.
- `Self` significa "el tipo que estamos implementando".
- `&self` es un método de solo lectura; `&mut self` puede cambiar el valor.
- `String::from("system")` crea un string con ownership.

## Qué implementar

Abre `src/ex05.rs`. El struct `Account` ya está definido.

| Método | Qué debe hacer |
| --- | --- |
| `Account::new(address)` | Crear una cuenta con cero lamports y dueño `"system"` |
| `deposit(amount)` | Agregar lamports |
| `withdraw(amount)` | Retirar lamports si es posible; retornar `true` si tuvo éxito, `false` si no |
| `balance_in_sol()` | Retornar SOL enteros, descartando el residuo |

Un retiro fallido debe dejar el saldo sin cambios. No restes primero para luego
intentar deshacerlo.

## Ejemplo resuelto

```rust
struct Point {
    x: i64,
    y: i64,
}

impl Point {
    fn new(x: i64, y: i64) -> Self {
        Self { x, y }
    }

    fn move_right(&mut self, steps: i64) {
        self.x += steps;
    }
}
```

`Self { x, y }` usa la forma abreviada de inicialización de campos: cuando el
nombre de la variable coincide con el nombre del campo, no repites `x: x`.

## Pistas

- En `new`, el parámetro ya se llama `address`, así que `Self { address, ... }`
  funciona.
- `deposit` cambia `self.lamports`; necesita `&mut self`.
- `withdraw` verifica primero `amount > self.lamports`. Retorna `false` de
  inmediato en esa rama.
- `balance_in_sol` es de solo lectura, así que recibe `&self`. Divide entre
  `1_000_000_000` y retorna un `u64`.
- Esta división es solo para mostrar. Nunca guardes dinero como un número de
  punto flotante.

## Tests

`cargo test --test ex05`

Hay cinco tests:

1. una cuenta nueva empieza vacía
2. un depósito agrega lamports
3. un retiro quita lamports
4. un retiro nunca deja la cuenta en negativo
5. el saldo se muestra en SOL enteros

## Terminado cuando

- `cargo test --test ex05` muestra `5 passed`.
- Puedes explicar la diferencia entre `&self` y `&mut self`.
- Puedes explicar por qué `withdraw` retorna `bool` en lugar de hacer panic.
