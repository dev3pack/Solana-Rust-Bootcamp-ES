# ex01 — Variables y tipos

**Objetivo:** aprender cómo Rust declara valores, cuándo un valor puede cambiar y
por qué el dinero usa `u64`.

## Conceptos

- `let` es inmutable por defecto.
- `let mut` habilita la mutación.
- El shadowing crea una nueva variable con el mismo nombre.
- `const` es un valor fijo en tiempo de compilación.
- `u64` es un entero sin signo de 64 bits. No puede ser negativo.
- La división entera descarta el residuo.
- `1_000_000_000` es el mismo número que `1000000000`; los guiones bajos son para
  humanos.

## Qué implementar

Abre `src/ex01.rs` y reemplaza cada `todo!()`.

| Función | Qué debe hacer |
| --- | --- |
| `sol_to_lamports(sol)` | Multiplicar los SOL enteros por `LAMPORTS_PER_SOL` |
| `lamports_to_sol(lamports)` | Dividir los lamports entre `LAMPORTS_PER_SOL`, descartando el residuo |
| `apply_bonus(balance, bonus)` | Sumar el bono y retornar el nuevo saldo |
| `double(value)` | Retornar el doble del valor, usando shadowing |
| `is_empty(balance)` | Retornar `true` solo cuando el saldo es cero |

`LAMPORTS_PER_SOL` ya está definido. No cambies su valor.

## Ejemplo resuelto

Esta es una función distinta, para que veas la forma sin copiar la respuesta:

```rust
let price = 10;          // inmutable
let mut count = 0;       // mutable
count += 1;
let count = count * 3;   // shadowing: una nueva variable
```

`count` ahora vale `3`. El primer `count` sigue existiendo conceptualmente, pero
el nombre ahora se refiere al nuevo.

## Pistas

- `LAMPORTS_PER_SOL` es un `u64`, así que multiplica un `u64` por él.
- `/` entre dos enteros trunca: `7 / 2` es `3`.
- Para `double`, escribe `let value = value * 2;` y luego retorna `value`. Eso es
  shadowing, no mutación.
- Para `is_empty`, una comparación como `balance == 0` ya produce un `bool`. No
  necesitas un `if`.
