# ex02 — Funciones y control de flujo

**Objetivo:** escribir funciones con tipos explícitos, retornar un valor desde la
última expresión y usar `for` e `if`.

## Conceptos

- La firma de una función indica el tipo de cada parámetro y el tipo de retorno.
- La última expresión sin punto y coma es el valor de retorno.
- `if` es una expresión: produce un valor.
- `for` recorre una colección.
- Un slice, `&[u64]`, es una vista prestada de una lista de números.
- `usize` es el tipo entero que se usa para longitudes y conteos.

## Qué implementar

Abre `src/ex02.rs`.

| Función | Qué debe hacer |
| --- | --- |
| `base_fee(signatures)` | Retornar `signatures * 5_000` lamports |
| `total(amounts)` | Sumar todos los montos y retornar la suma; un slice vacío suma cero |
| `count_above(amounts, threshold)` | Contar los montos estrictamente mayores que el umbral |
| `clamp_transfer(amount, balance)` | Retornar el menor de los dos valores |

`base_fee` es solo la comisión base. Solana suma las comisiones de prioridad por
separado; no las incluyas aquí.

## Ejemplo resuelto

```rust
fn double(n: u64) -> u64 {
    n * 2
}
```

No hay `return` ni punto y coma. La expresión `n * 2` es el valor de la función.
Si escribes `n * 2;`, la función retorna `()` y el compilador reporta que los
tipos no coinciden.

## Pistas

- `for amount in amounts` te da una referencia a cada número. Lee el número con
  `*amount` cuando lo compares o lo sumes.
- Empieza `total` con `let mut sum = 0;` y suma cada monto.
- Para `count_above`, inicia un contador en `0` e increméntalo dentro de un `if`.
- `clamp_transfer` puede ser una sola expresión `if`/`else`: retorna `balance`
  cuando el monto es mayor; si no, retorna el monto.
- El tipo de retorno `usize` es el tipo que `count` inferirá cuando lo retornes.
