# ex04 — Borrowing

**Objetivo:** prestar un valor en lugar de moverlo, y cambiar un valor a través
de una referencia mutable.

## Conceptos

- `&T` es una referencia compartida: muchos lectores, ningún escritor.
- `&mut T` es una referencia mutable: exactamente un escritor, sin lectores al
  mismo tiempo.
- La regla de oro: muchos `&` **o** un `&mut`, nunca ambos.
- Una referencia nunca es dueña del valor. El dueño lo mantiene vivo.
- Desreferencia una referencia mutable con `*` para cambiar el valor detrás de
  ella.

## Qué implementar

Abre `src/ex04.rs`.

| Función | Qué debe hacer |
| --- | --- |
| `total(amounts)` | Leer un slice prestado y retornar la suma |
| `add_fee(amount, fee)` | Sumar la comisión al valor de quien llama; no retornar nada |
| `count_writable(flags)` | Contar los valores `true` en un slice prestado |
| `append_note(history, note)` | Agregar una copia con ownership de la nota al historial de quien llama |

## Ejemplo resuelto

```rust
let mut balance = 100;
let fee = 5;

let reader = &balance;   // préstamo compartido
println!("{reader}");    // último uso del préstamo compartido
// reader ya no se usa después de este punto

let writer = &mut balance;
*writer += fee;          // cambia el valor detrás de la referencia
```

El préstamo compartido debe terminar antes de que empiece el préstamo mutable.
El compilador hace cumplir el orden.

## Pistas

- `for amount in amounts` produce `&u64`. Usa `*amount` para leer el número.
- `add_fee` debe escribir a través de la referencia: `*amount += fee;`.
- `count_writable` puede usar `if *flag { ... }`.
- `append_note` recibe `&str`; usa `note.to_string()` antes de hacer push,
  porque el historial es dueño de sus strings.
- No necesitas `.clone()` sobre todo el vector. Préstalo de forma mutable y haz
  push.

## Tests

`cargo test --test ex04`

Hay cinco tests:

1. leer un slice no vacío
2. leer un slice vacío
3. una comisión cambia el valor de quien llama
4. se cuentan las cuentas escribibles
5. se agrega una nota al historial

## Terminado cuando

- `cargo test --test ex04` muestra `5 passed`.
- Puedes enunciar la regla de oro sin mirar la diapositiva.
- Puedes explicar por qué `add_fee` retorna `()` pero aun así cambia el valor de
  quien llama.
