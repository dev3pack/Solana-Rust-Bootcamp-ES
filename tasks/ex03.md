# ex03 — Ownership

**Objetivo:** ver cómo ocurre un move, tomar ownership en una función y retornar
un valor con ownership.

## Conceptos

- Cada valor tiene exactamente un dueño.
- Asignar un `String` lo mueve; la variable anterior ya no se puede usar.
- Pasar un `String` a una función lo mueve dentro de la función.
- Retornar un `String` devuelve el ownership a quien llama.
- `&str` es un slice de string prestado. Quien llama conserva el ownership.
- `.to_string()` crea un `String` con ownership a partir de un `&str`.
- Una tupla puede retornar más de un valor.

## Qué implementar

Abre `src/ex03.rs`.

| Función | Qué debe hacer |
| --- | --- |
| `make_label(owner)` | Tomar un nombre con ownership y retornar `"account:<nombre>"` |
| `duplicate(text)` | Retornar una copia con ownership de un string prestado |
| `take_and_return(account)` | Retornar la cuenta junto con su longitud |
| `consume_all(accounts)` | Consumir un `Vec<String>` y retornar cuántos nombres contenía |

## Ejemplo resuelto

```rust
let name = String::from("alice");
let moved = name;
// println!("{name}"); // E0382: préstamo de un valor movido
println!("{moved}");   // bien
```

`name` no es una copia del texto. El dueño cambió. Si necesitas dos dueños,
tienes que pedir un clon explícitamente:

```rust
let name = String::from("alice");
let copy = name.clone();
println!("{name} {copy}"); // ambos son válidos
```

Clonar está permitido cuando de verdad necesitas dos valores con ownership. No
clones solo para silenciar al compilador; primero pregúntate si un préstamo
bastaría.

## Pistas

- `format!("account:{owner}")` construye un `String` y mueve `owner` a los
  argumentos de formato. Esa es exactamente la transferencia de ownership que
  busca este ejercicio.
- `duplicate` recibe un `&str`; llama `.to_string()` sobre él.
- En `take_and_return`, lee la longitud antes de retornar el `String`. Retornar
  la tupla mueve ambos valores a quien llama.
- `consume_all` recibe el vector por valor. `.len()` lo presta por un momento; el
  vector se libera cuando termina la función.
