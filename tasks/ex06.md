# ex06 — Enums y `match`

**Objetivo:** modelar un conjunto fijo de formas de instrucción y manejar cada
caso.

## Conceptos

- Un enum es un valor que es una de varias variantes.
- Las variantes pueden ser tipo struct (`Transfer { ... }`), tipo tupla
  (`Close(String)`) o no llevar datos.
- `match` selecciona una rama y enlaza los datos dentro de la variante.
- `match` debe ser exhaustivo: cada variante necesita un brazo.
- `..` ignora los campos restantes de una variante tipo struct.
- Retornar `&str` desde una función que presta un `Instruction` es seguro porque
  la referencia retornada apunta dentro de la instrucción.

## Qué implementar

Abre `src/ex06.rs`. El enum `Instruction` ya está definido.

| Función | Qué debe hacer |
| --- | --- |
| `kind(ix)` | Retornar `"transfer"`, `"create"` o `"close"` |
| `lamports_moved(ix)` | Retornar los lamports para `Transfer`; si no, `0` |
| `account_touched(ix)` | Retornar el remitente, la nueva dirección o la dirección cerrada |

## Ejemplo resuelto

```rust
enum Shape {
    Circle(f64),
    Square { side: f64 },
}

fn area(shape: &Shape) -> f64 {
    match shape {
        Shape::Circle(radius) => 3.14159 * radius * radius,
        Shape::Square { side } => side * side,
    }
}
```

No hay brazo `_` porque ambas variantes están cubiertas. Si más adelante agregas
una variante `Triangle`, esta función deja de compilar hasta que la manejes. Eso
es una ventaja, no un error.

## Pistas

- En `kind`, usa `Instruction::Transfer { .. } => "transfer"` y brazos similares.
- En `lamports_moved`, enlaza el campo con
  `Instruction::Transfer { lamports, .. } => *lamports`. El campo está prestado,
  así que desreferéncialo para retornar un `u64`.
- En `account_touched`, enlaza `from`, `address` o el campo de la tupla y
  retórnalo directamente. El compilador infiere el lifetime a partir de la única
  referencia de entrada.
- No uses `_` en `kind` ni en `account_touched`; parte del ejercicio es nombrar
  cada variante.

## Tests

`cargo test --test ex06`

Hay cuatro tests:

1. el tipo transfer
2. los tipos create y close
3. solo transfer mueve lamports
4. cada variante tiene una cuenta principal

## Terminado cuando

- `cargo test --test ex06` muestra `4 passed`.
- Puedes explicar qué pasa cuando se agrega una nueva variante al enum y el
  `match` no se actualiza.
- Puedes explicar la diferencia entre los datos de la instrucción y las cuentas
  que llegan en el `Context`.
